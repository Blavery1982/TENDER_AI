# CORE knowledge

Здесь хранятся только проверенные детерминированные правила TENDER_AI.

Новое правило сначала оформляется как `CORE_RULE_CANDIDATE`. AI не имеет права
записывать его в `approved_rules.json`. Добавление выполняется разработчиком
после человеческой проверки, отдельного теста и явного принятия правила.

Словари и точные сопоставления следует хранить в JSON. Сложную проверяемую
логику — в Python-модуле соответствующего skill. Каждое принятое правило должно
иметь regression-тест.
