# Поиск цены точной модели

Запуск из папки проекта:

```bash
.venv/bin/python main.py --price-search-test "Royal Clima RC-TWN28HN"
```

Вход — полное точное название конкретной модели, содержащее однозначный артикул/SKU.

Подробный результат сохраняется в `data/model_price_search_live_test.json`. В нём находятся найденные товарные
страницы, продавцы, подтверждённые публичные цены, наличие, прямые URL, время проверки и ошибки отдельных источников.

Candidate discovery выполняется каскадом через Яндекс Маркет и публичные внутренние поисковые страницы российских
магазинов: XCOM, KNS, Ситилинк, ВсеИнструменты, ОНЛАЙН ТРЕЙД, DNS, М.Видео, Royal-Rus, ClimaArt и SDK-Climat.
Недоступность одного источника не останавливает остальные.

Цена подтверждается только содержимым самой найденной товарной страницы: структурированными данными Product/Offer
либо однозначно подписанной текущей ценой. Поисковые фрагменты не являются доказательством цены.

Exact-model validation обязательна. Страница принимается только при подтверждении точного SKU; похожие модели,
включая отличающиеся суффиксами `/IN`, `/OUT` и другими обозначениями, исключаются.
