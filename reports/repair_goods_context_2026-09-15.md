# Ремонтные комплекты как товар

Текущая детерминированная логика уже сохраняет `goods` для «Ремонтный комплект»
и «Комплект для ремонта». Совпадение «ремонт» получает `product_property`,
`affects_decision=false`; модель самого комплекта может использоваться для
товарного поиска после goods-gate.

Добавлены 5 самостоятельных regression-тестов без сети и Google Sheets:
оба варианта комплекта (с категорией ТОВАРЫ и без неё), самостоятельный ремонт,
приоритет РАБОТЫ и исходная ремонтная позиция закупки 200909993126100032.

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B -m unittest tests.test_repair_goods_context
```

Результат: 5/5 OK. Runtime-код менять не потребовалось.
Уточнение закреплено в AGENTS.md. Полный suite не запускался, UNIT в Google
Sheets не записывались.

Первоначальный запуск выбранных тестов из `tests.test_position_kind_gate`
не дошёл до проверок: импорт pipeline требует отсутствующий в текущем `.venv`
модуль `google_auth_oauthlib`. Окружение не изменялось; новый узкий модуль
проверяет реальные функции классификатора, фильтра и допуска моделей/цен
без этой внешней зависимости.
